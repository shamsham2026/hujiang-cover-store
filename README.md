# 滬江小學 調課 · 代課

給教務查看全校課表、安排調課或代課，並對照 [這份 Google 試算表](https://docs.google.com/spreadsheets/d/1pfui330JBwmCFG-e9am7cBjPdfD-A1pMt4_cNgtrsek/edit)。

網頁直接讀試算表的「排課資料庫」、「調課暫存」、「總紀錄表」和「校外導師不可調動」。安排先存在這部瀏覽器，列印調課紙不必先寫回試算表。

## 本地執行

```bash
npm install
npm run dev -- --port 43123 --hostname 0.0.0.0
```

開啟 [http://127.0.0.1:43123](http://127.0.0.1:43123)。

規則測試：

```bash
npm run test:rules
```

## 調課規則

1. **代課**順位：曉晴、朗有空就排最前；其次當日空堂較多；再其次總紀錄表裡曾請假較多；最後是曾經教該班。不符合早會資格或該節已有課的老師不進順位。
2. **調課**只找教同一班的老師。先同日對調，再同日三方、四方，最後跨日。每一圈的最後一節回到原老師。
3. **當值**（當值、放學、早會、小息、午膳、午息、班主任節）只可代課或改日對調，不可同日對調。
4. 早會前拆成 **7:30** 與 **7:45**。7:30 只限主任及副校；7:45 只限主任及非班主任名單。莉不代早會。名單在 `lib/staff.ts`。
5. 不能直接對調時，列出多方調課，整圈一次採用。
6. 場地上限：體育每節 2 班、電腦室 1 班、高小視藝室 1 班、高小音樂 408室 1 班、低小音樂室 1 班。同一班對調若沒有增加班數，不會誤報。
7. 同一節、同一班、同一科有兩位老師，或 4A英文、4B中文、4D數學（部份）、3C中文、5B中文、6A／6B中文，都視為合教，兩位老師都要能調。
8. **英閱**是合教，而且英語室每節最多一班。
9. 「查找」可以看一位老師的一週課表，以及某一節誰有空。
10. 確認前可下載代課安排或調課安排的清晰圖片，也可以分享圖片。同日只顯示當天；跨日調課和當值對調會並列兩天。對調可指定上回日期，只搜那一天。校外導師課堂只可跟校外導師對調；指定日期時，對方必須是該日的校外導師課堂。統計頁計算請假時數與代課時數。安排頁可複製確定連結。同事開啟後按「確定」，會經網頁應用程式寫入調課暫存（兩人對調用 `swapLessonsBatch`，代課和多方用 `writeTempEntries`），並在該列記下「已確定」。首頁列出新確認。沒有網址時不會改試算表。

## 寫回試算表

`gas/Code.gs` 與 `gas/Index.html` 是優化後的 Apps Script。

1. 試算表選「擴充功能 → Apps Script」。
2. 用 `Code.gs` 取代 `程式碼.gs`，新增 HTML 檔 `Index`，貼上 `Index.html` 的內容。
3. 部署為網頁應用程式：執行身分選「我」，存取權選「任何人」。
4. 把網址貼到網頁「安排」頁的欄位。確認安排時會寫入「調課暫存」和「代課表格」。

兩人對調用 `swapLessonsBatch`（一對只寫兩列）。代課用 `writeSubstitute`，並用 `writeTempEntries` 逐節寫入調課暫存。三人或以上每一節一列，不會把每一腳再寫成一對。沒有網址或寫入失敗時，畫面上的最新課表仍會更新，頁面會說明試算表沒有改。舊的網頁應用程式需要重新部署，才認得 `writeTempEntries`。

試算表需維持「知道連結的任何人可以檢視」，網頁才讀得到最新課表。寫入仍只透過已部署的 Apps Script。
